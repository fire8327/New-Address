# Новый Адрес — Агентство недвижимости (г. Канаш)

> Премиальный архитектурный веб-лендинг агентства недвижимости «Новый Адрес» (г. Канаш, Чувашская Республика).
> Разработан в швейцарском модернистском стиле (Swiss Architectural & Modernist Grotesque): акцентная типографика, чистый кобальтовый цвет (`#0052FF`), строгая модульная сетка и отсутствие шаблонного «ИИ-визуала».

---

## 🏛 Особенности проекта

- **Швейцарский минимализм:** Строгая сетка, моноширинные технические метрики, гротескные заголовки.
- **Реалистичный контекст города:** Все объекты, улицы (ул. 30 лет Победы, пр-т Ленина, ул. Железнодорожная, Большие Бикшихи) и цены полностью выверены по реальному рынку Канаша (база Авито и Домклик).
- **Интерактивный блок «Радар ликвидности & Оценка недвижимости»:**
  - Динамический расчет рыночной стоимости по формулам и коэффициентам Канаша.
  - Учет индивидуального газового отопления (+15% к стоимости в Чувашии), типа дома (кирпич/панель), этажности, ремонта и микрорайона.
  - Расчет срока экспозиции и вероятности продажи за 30 дней.
- **Открытый реестр недавних сделок:** Прозрачная таблица фактически закрытых сделок (цена старта, финальная сумма продажи, срок реализации).
- **Модальное бронирование:** Всплывающее окно записи на просмотр и фиксации условий с защитой от спама.

---

## 🛠 Стек технологий

- **HTML5** (семантическая разметка, Open Graph, meta viewport)
- **Tailwind CSS (CDN)** с кастомной швейцарской палитрой (Cobalt `#0052FF`, Surface `#F7F8FA`, Slate, Jet)
- **Шрифты:** Space Grotesk, Inter, JetBrains Mono (Google Fonts)
- **Vanilla JavaScript:** Реактивный расчет калькулятора, фильтрация каталога, валидация и отправка заявок
- **Node.js:** Легковесный статический HTTP-сервер (`server.js`) без внешних зависимостей

---

## 🚀 Быстрый запуск

### Вариант 1: Через Node.js сервер
```bash
node server.js
```
Сервер запустится по адресу: `http://localhost:3000`

### Вариант 2: Прямое открытие
Просто откройте файл `index.html` в любом современном браузере.
